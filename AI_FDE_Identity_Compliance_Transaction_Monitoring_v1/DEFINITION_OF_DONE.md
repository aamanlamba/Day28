# Definition of Done
A change is done only when:
- Approved requirements and acceptance criteria are satisfied.
- Targeted tests pass.
- Full legacy regression suite passes, or an approved change record explains intentional updates.
- Security/privacy checks relevant to the change pass.
- API/data contract impact is documented.
- Traceability matrix is updated.
- Evidence record contains commands, results and residual risks.
- No unresolved high-severity ambiguity remains.
- Documentation reflects actual implemented behavior.
