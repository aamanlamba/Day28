# Workshop Challenge Map

Participants should first run the baseline, then investigate rather than immediately rewrite.

1. Reproduce `/v1` identity behavior and document its weaknesses.
2. Run `/v2` integrated cases and inspect identity-to-monitoring lineage.
3. Fix one challenge at a time with a test-first change.
4. Add adversarial/edge datasets before adjusting thresholds.
5. Keep rule facts deterministic; introduce AI only behind typed interfaces.
6. Demonstrate rollback and backwards compatibility.
7. Produce a release-evidence pack: tests, evals, threat model, residual risks and traceability.
